# Chess Coach

Настольное приложение-тренер по шахматам. Отдельный проект, к «Каспийскому диспетчеру» не относится.

- **Игра с ботом.** Партия против Stockfish, 8 уровней силы. Тренер оценивает каждый ваш ход, даёт подсказку в два шага (сначала фигура, потом ход) и показывает, что грозит соперник.
  Часы (от пули 1+0 до рапида 15+10 или без часов), сдача, предложение ничьей (бот соглашается, если ему хуже или позиция равная после 20 ходов), выбор фигуры при превращении пешки, звуки ходов. Ничья по пату, троекратному повторению, правилу 50 ходов и нехватке фигур.
- **Два игрока.** За одним компьютером (доска поворачивается к тому, кто ходит) или по сети: один жмёт «Создать игру» и получает код — адрес компьютера в локальной сети, второй вводит код и жмёт «Подключиться». Часы, сдача, ничья, реванш со сменой цвета. Связь напрямую между приложениями (порт 47615), без сервера. Через интернет — в одной виртуальной сети (Radmin VPN, ZeroTier, Tailscale) или с пробросом порта 47615 на роутере. При первом создании игры Windows спросит про брандмауэр — разрешите доступ в частных сетях.
- **Боты-персонажи.** Восемь соперников от Малого Ахмеда (~700) до Машины (~2600): у каждого свой стиль (осторожный дед, агрессивный тигр, тролль, который гуляет королём) и фразы по ходу партии.
- **Шахматы 960.** Случайная расстановка фигур — против бота и вдвоём, в том числе по сети.
- **История и дебюты.** Все законченные партии сохраняются (кнопка «📜 История»), любую можно открыть в разборе. Название дебюта видно во время игры и в разборе.
- **Достижения.** 33 ачивки со всплывашками (кнопка «🏆 Достижения»): мат конём, взятие на проходе, победа над каждым персонажем и т. д.
- **Тренер «без цензуры».** По желанию ругается за ошибки и хвалит за сильные ходы, голосом (записи ElevenLabs в `public/voice`, остальное — голос Windows Pavel).
- **Клипы для соцсетей.** Кнопка «🎬 Клип момента» (и «Клип лучшего момента» в конце партии) записывает вертикальное видео 9:16 на 6–12 секунд: последние ходы, сам ход с пометкой, реплика тренера крупно и его голос, в конце — «Сыграй сам». MP4 (или WebM, если браузер не умеет MP4); на телефоне — кнопка «Поделиться».
- **Разбор партии.** Вставьте PGN своей сыгранной партии (или откройте файл): оценка каждого хода, график, лучший ход и продолжение для каждой ошибки.
- **Тренировка ошибок.** Позиции, где вы ошиблись, превращаются в задачи: найдите ход сильнее.

Подсказки работают только против бота и в разборе уже сыгранных партий. Во время партий с людьми приложение не помогает.

## Запуск

Нужен Node.js 20+.

```
npm install
npm run app     # собрать и открыть окно приложения
npm run dev     # режим разработки в браузере
npm run dist    # установщик/портативный файл в release/ (собирать на своей ОС)
```

### Сайт

`npm run build` собирает в `dist/` статический сайт: его можно положить на любой хостинг (GitHub Pages, Cloudflare Pages, Netlify). Работает в браузере на компьютере и телефоне, ставится как приложение (PWA) и после первого открытия работает без интернета. Отличия от приложения: игры по сети пока нет, а фразы без записи озвучивает голос браузера (в клипы они идут без голоса).

Адрес сайта для подписи на клипах и кнопки «Ссылка на игру» задаётся при сборке:

```
VITE_SITE_URL=https://example.com/ npm run build
```

### Ярлык на рабочем столе (Windows)

Дважды щёлкните `install-windows.bat`: он поставит зависимости, соберёт приложение и создаст ярлык «Chess Coach» на рабочем столе. Папку проекта после этого не переносите — ярлык ссылается на неё.

## Из чего сделано

- доска — [chessground](https://github.com/lichess-org/chessground), правила и PGN — [chessops](https://github.com/niklasf/chessops) (обе библиотеки Lichess);
- движок — Stockfish 19 (wasm, однопоточная lite-сборка) в Web Worker, работает без интернета;
- окно — Electron, интерфейс — TypeScript + Vite.

Все числа (оценка, лучший ход) считает движок; тексты пояснений — шаблоны по этим числам.
